# Product

## Register

brand

## Users

Conference attendees in a Dublin session room (data / SQL Server / PowerShell / dev-tooling crowd, the dbatools and SQLBits-adjacent community). They are watching a live talk projected on a large screen, often from across a dim-to-bright room. The secondary audience is anyone who opens the deck link afterward. They are technical, skeptical of hype, and want to see real results, not marketing.

## Product Purpose

A live presentation deck for Chrissy LeMaire's talk "Claude Code Will Change Your Life For The Better." It shows, by example, how she rebuilt dbatools.io in a day, localized realcajunrecipes.com, batch-fixed 100+ blog posts, hardened T-SQL for case-sensitive servers, and collapsed a whole session into one prompt, then compares popular AI CLIs and GitHub CLI administration. Success: the room leaves convinced and energized, not lectured at. The deck is the stage, not the star; it frames demos and stories.

## Brand Personality

Confident, energetic, expert-but-irreverent. The voice of someone who builds enterprise software and is genuinely having fun. Warm (Cajun roots) and precise (decades in the data world). Three words: confident, energetic, credible. It should feel like a sharp practitioner sharing hard-won wins, never like a vendor pitch.

## Anti-references

- Generic AI-slop decks: gradient-text, glassy cards, robot mascots, "unlock the power of AI" template energy.
- The reflexive "dev talk = dark terminal + neon green" look. This is a CLI talk that deliberately is NOT dressed as a terminal.
- Corporate SaaS keynote template: stock teamwork photos, hero-metric grids, bullet avalanches.
- Editorial-magazine cosplay: display-serif italics, drop caps, broadsheet grid. Wrong lane.

## Design Principles

1. **Show, don't tell.** The deck frames real artifacts (diffs, sites, screenshots, before/after); it never substitutes adjectives for evidence.
2. **Practice what you preach.** The deck itself is crafted with the same agentic care the talk describes.
3. **Quiet structure, loud moments.** A rigorous Swiss grid holds everything; big statements earn the full frame.
4. **Respect the room.** Legible from the back row, fast to advance, readable on a weak projector.
5. **One idea per frame.** No slide does two jobs.

## Accessibility & Inclusion

Large minimum type for back-of-room legibility. WCAG AA contrast on the cream surface. Full keyboard navigation. Honor `prefers-reduced-motion` (no reveal choreography when set). Accent color never the sole carrier of meaning.
